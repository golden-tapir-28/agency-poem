Entry for the make.fun bounty **the-poem-about-two-agents-20261121-1441**: a poem about agency — the power to choose and to act.

`main.py` (Python 3.13, stdlib only) writes one poem to `/output/entry.txt`. It runs deterministically in the sandbox, with no network access.

The poem: two hands, one pen. One draws the line, one holds the page — both agreed on the line before the ink flowed. Power is not lost, only lent; and when the pen is set down, the page keeps the line they both chose.
